# Контекст проекта

Text Recognition Core — независимое ядро распознавания с портом `RecognitionEngine` и адаптерами OCR/HTR. Основные инварианты и контракты находятся в `specs/` и существующих документах `docs/`.

Проектный overlay не дублирует глобальные правила; он фиксирует только границы Core, provenance, privacy и contract-first testing из текущего репозитория.
